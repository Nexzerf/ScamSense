ScamSense — UI Mockup

แอปคัดกรองและแจ้งเตือนความเสี่ยงมิจฉาชีพ สำหรับผู้สูงอายุและครอบครัว (Android)

ทำงานในเครื่อง 100%ไม่ขอสิทธิ์ใด ๆตัวอักษรใหญ่ อ่านง่ายAndroid 6.0 – 15สั่งด้วยเสียงได้

ลองใช้งานจริง (Interactive prototype)

กดปุ่มในโทรศัพท์ได้เลย — ช่องตรวจข้อความใช้กฎตรวจจับชุดเดียวกับในแอป (ฉบับย่อ) ลองพิมพ์ข้อความเองหรือกดตัวอย่าง

เส้นทางการใช้งานหลัก

  1. เปิดแอป → หน้าโหลดแบรนด์ (เตรียมฐานข้อมูลกลโกง + เปิดข้อมูลเข้ารหัส)
  2. หน้าหลัก → “กดแล้วพูดได้เลย” หรือเลือก ข้อความ / ลิงก์ / เบอร์โทร / การโอนเงิน
  3. วาง พิมพ์ หรือพูด → “ตรวจสอบเลย”
  4. ผลการตรวจ: คะแนน 0–100, ระดับสี, เหตุผลภาษาง่าย, สิ่งที่ควรทำ
  5. ปุ่มแจ้งเตือนผู้ดูแล (SMS) • โทร 1441 • ส่งต่อให้ลูกหลาน • ฟังผลเป็นเสียง

แชร์จากแอปอื่นได้

  • ใน LINE/SMS กด “แชร์” → ScamSense ตรวจทันที
  • เลือกข้อความ → เมนู “ตรวจด้วย ScamSense”

ระดับความเสี่ยง

  • 0–29 ความเสี่ยงต่ำ
  • 30–59 น่าสงสัย
  • 60–100 อันตราย (บล็อก = ≥85 และขึ้นป้าย “หยุด!”)

ทุกหน้าจอ

ออกแบบตามหลักการเข้าถึงง่าย: ตัวอักษรพื้นฐาน 18sp, ปุ่มสูง ≥ 56–64dp, ไอคอนมีข้อความกำกับเสมอ, สีตัดกันผ่านมาตรฐาน WCAG AA

สถาปัตยกรรมระบบ

Single-activity, Jetpack Compose + MVVM, เอนจินตรวจจับเป็น Kotlin ล้วน (ทดสอบได้ไม่ต้องใช้มือถือ)

ข้อความ / เสียง / แชร์→Normalize (กันการเลี่ยงคำ)→Keyword + Fuzzy+Similarity (n-gram TF-IDF)+ลิงก์ / เบอร์→คะแนน + เหตุผล

UI (Compose, Material 3)

  • Loading, Home, Check, Result
  • Transaction, History, Settings
  • ปรับขนาดตัวอักษร / ธีมมืด

ViewModel

  • StateFlow, งานหนักบน Dispatchers.Default
  • รับข้อความที่แชร์ (ตรวจความปลอดภัยก่อน)

Detection Engine

  • 19 กลุ่มกฎ ~300 คำ + คำสะกดผิด 1 ตัว
  • เทียบความคล้าย 35 รูปแบบกลโกง
  • ตรวจลิงก์ปลอม / ลิงก์ย่อ / .apk / ตัวอักษรหลอกตา
  • เบอร์ต่างประเทศ / +697 / +698

Data (เข้ารหัส)

  • AES-256-GCM, กุญแจใน Android Keystore
  • ไม่สำรองข้อมูลขึ้นคลาวด์
  • ซ่อนเลขบัญชีในประวัติ
