# ฟังระหว่างคุย (Live call listening) — ทดลอง

ScamSense ฟัง**เสียงปลายสาย**ระหว่างคุยกับเบอร์ที่ไม่อยู่ในรายชื่อผู้ติดต่อ แปลงเป็นข้อความภาษาไทย**ในเครื่อง** แล้วตรวจด้วยตัวตรวจจับเดียวกับที่ใช้ตรวจข้อความ ถ้าปลายสายพูดแบบมิจฉาชีพ เครื่องจะสั่นและพูดเตือนเข้าหูฟังทันที และถ้าแน่ใจระดับ "บล็อก" (เช่น ขอ OTP พร้อมเร่งรัด, ให้โอนเข้า "บัญชีปลอดภัย") จะ**วางสายให้อัตโนมัติ**ภายใน 4 วินาที โดยแตะยกเลิกได้

```
รับสายจากเบอร์ไม่รู้จัก
  → (Shizuku) เปิดโปรเซส app_process สิทธิ์ shell ที่อัดเสียง VOICE_DOWNLINK = เสียงปลายสายเท่านั้น
    (ไม่ใช้ "user service" ของ Shizuku เพราะบน ColorOS บางรุ่นตัวเริ่มของมัน crash)
  → ท่อ (pipe) ส่ง PCM 16 kHz ให้แอป — ไม่บันทึกลงเครื่อง
  → SpeechChunker ตัดเป็นช่วงพูดสั้น ๆ (≤ 7 วินาที)
  → whisper.cpp แปลงเป็นข้อความไทยในเครื่อง
  → LiveCallMonitor (ScamAnalyzer ตัวเดียวกับในแอป) ดูหลายประโยคต่อเนื่อง
  → ระวัง (สั่น) / อันตราย (สั่น + เสียงเตือน) / บล็อก (นับถอยหลังแล้ววางสาย)
  → จบสาย: บันทึกผลและข้อความย่อ (ปิดบังเลขยาว) ลงประวัติที่เข้ารหัส
```

## ต้องเตรียม (ให้ลูกหลานตั้งค่า ครั้งเดียว)
1. มือถือ **Android 11 ขึ้นไป** และต่อ **Wi‑Fi**
2. เปิดโหมดนักพัฒนา: ตั้งค่า → เกี่ยวกับโทรศัพท์ → แตะ "หมายเลขบิลด์" 7 ครั้ง
3. ใน ScamSense: **ตั้งค่า → ป้องกันสายโทร → ฟังระหว่างคุย** กด **"เริ่มจับคู่"**
   - แอปจะเปิดหน้าตัวเลือกสำหรับนักพัฒนาให้ → เปิด **การแก้ไขข้อบกพร่องแบบไร้สาย** → แตะเข้าไป → **จับคู่อุปกรณ์ด้วยรหัสจับคู่**
   - ลากแถบแจ้งเตือนลง พิมพ์รหัส 6 หลัก เว้นวรรค ตามด้วยเลขพอร์ต (ตัวเลขหลัง : ในบรรทัด IP ของหน้าต่างจับคู่) เช่น `123456 41235` ลงในการแจ้งเตือนของ ScamSense แล้วกดส่ง
4. อนุญาต "รู้ว่ารับสายหรือวางสายแล้ว", ดาวน์โหลดโมเดล แล้วเปิด "ฟังระหว่างคุย"

### โหมดในตัว (Built-in) ทำงานอย่างไร
ScamSense ต่อเข้า ADB ของเครื่องตัวเองผ่าน "การแก้ไขข้อบกพร่องแบบไร้สาย" (ใช้ libadb-android + spake2-java) จึง**ไม่ต้องลงแอป Shizuku**
- จับคู่ครั้งเดียว: แอปเก็บกุญแจของตัวเองไว้ในพื้นที่ส่วนตัวของแอป ครั้งต่อไปเชื่อมต่อได้เอง
- หลังจับคู่ แอปขอสิทธิ์ `WRITE_SECURE_SETTINGS` ผ่าน ADB ครั้งเดียว เพื่อ**เปิด "การแก้ไขข้อบกพร่องแบบไร้สาย" ให้เองเมื่อมีสาย** แม้รีสตาร์ทเครื่องแล้ว (ต้องอยู่บน Wi‑Fi ที่เคยอนุญาต)
- หาพอร์ต: ลองหาแบบ mDNS ก่อน ถ้าไม่เจอ (เช่นบน ColorOS) จะไล่ลองพอร์ตบนเครื่องตัวเอง (127.0.0.1 และ IP Wi‑Fi) ไม่กี่วินาที
- เมื่อมีสาย: เปิดตัวดึงเสียง (`ShellMain`) ด้วยคำสั่ง `exec:` ผ่านการเชื่อมต่อนี้ เสียงไหลกลับมาทางเดียวกัน วางสายด้วย `input keyevent KEYCODE_ENDCALL`
- บันทึกการเชื่อมต่อ: กด "ดูบันทึกการเชื่อมต่อ" ในแอป หรือ `adb logcat -s SS:Adb`
- ถ้าโหมดในตัวใช้ไม่ได้ และมีแอป Shizuku ทำงานอยู่ แอปจะใช้ Shizuku แทนอัตโนมัติ

## ทดสอบโดยไม่ต้องโทร
ในหน้า **ป้องกันสายโทร → ข้อ 3** กด **"ทดสอบการฟัง"** แล้วพูดใส่มือถือ 6 วินาที แอปจะแสดงคำที่ได้ยิน เวลาที่ใช้แปลงเสียง และคะแนนความเสี่ยง ถ้าขึ้นว่า "ช้าเกินไป" ให้เปลี่ยนเป็นโมเดล "เร็ว"

ระหว่างสายจริง การแจ้งเตือน "ScamSense ฟังสายนี้อยู่" จะแสดง **"ได้ยินล่าสุด: …"** ทุกครั้งที่แปลงเสียงได้ ถ้า 12 วินาทีแรกไม่ได้ยินเสียงปลายสายเลย จะแจ้งว่าเครื่องอาจปิดกั้นเสียงในสาย

## โมเดลภาษาไทย (Thonburian Whisper)
โมเดลที่ฝึกด้วยภาษาไทยของ BiodatLab ม.มหิดล (`biodatlab/distill-whisper-th-small`) ไม่มีไฟล์รูปแบบ whisper.cpp ให้ดาวน์โหลด แอปจึงทำให้เองในเครื่อง:
1. ดาวน์โหลด config.json, vocab.json และ safetensors จาก Hugging Face (ครั้งเดียว ~0.5–1 GB ใช้ Wi-Fi)
2. แปลงเป็น whisper.cpp ด้วย `HfWhisperToGgml` (Kotlin, ทดสอบแล้วว่าได้ไฟล์ตรงกับ convert-h5-to-ggml.py ของ whisper.cpp ทุกไบต์)
3. ย่อเป็น q5_1 ด้วยตัว quantize ของ whisper.cpp แล้วลบไฟล์ชั่วคราว

ทางเลือก: แปลงบนคอมด้วย `tools/convert_thonburian.py` แล้ว "นำเข้าไฟล์โมเดล" ในแอป

## ข้อจำกัดที่ต้องรู้
- ต้องเปิดโหมดนักพัฒนาไว้ แอปธนาคารบางแอปอาจไม่ยอมทำงานขณะเปิดโหมดนี้
- การฟังระหว่างคุยใช้ได้เฉพาะตอนต่อ Wi‑Fi (ข้อจำกัดของ "การแก้ไขข้อบกพร่องแบบไร้สาย")
- ความแม่นของการแปลงเสียงไทยผ่านสายโทรศัพท์ **ยังไม่ได้ทดสอบกับสายจริง** — ต้องทดลองและปรับก่อนใช้งานจริง
- ค่าเริ่มต้นคือโมเดล "เร็ว" (~57 MB) โมเดล "แม่นยำ" (~180 MB) ต้องใช้มือถือแรง (RAM 6 GB ขึ้นไป)
- พฤติกรรมของการดึงเสียงในสายต่างกันตามยี่ห้อ/รุ่น บางรุ่นอาจไม่อนุญาตเลย (แอปจะแจ้ง "เครื่องนี้ไม่อนุญาตให้ฟังเสียงในสาย")
- สายผ่าน Wi‑Fi calling (VoWiFi) อาจดึงเสียงไม่ได้
- **ขึ้น Google Play ไม่ได้** (นโยบายเรื่องการเข้าถึงเสียงในสาย) — แจกเป็นไฟล์ APK
- การเตือนด้วยเสียงเล่นทางหูฟัง ถ้าเปิดลำโพง ปลายสายอาจได้ยินด้วย

## ความเป็นส่วนตัวและกฎหมาย
- ฟังเฉพาะสายจากเบอร์ที่**ไม่อยู่ในรายชื่อผู้ติดต่อ** และเฉพาะ**เสียงปลายสาย** (ถ้าเครื่องไม่รองรับจะใช้เสียงทั้งสองฝั่ง)
- เสียงไม่ถูกบันทึกและไม่ออกนอกเครื่อง; เก็บเฉพาะผลการตรวจ + ข้อความย่อที่ปิดบังเลขยาว ในประวัติที่เข้ารหัส
- การฟัง/ถอดความสนทนาโทรศัพท์อยู่ภายใต้ PDPA — ควรปรึกษาผู้เชี่ยวชาญด้านกฎหมายก่อนใช้งานจริงในวงกว้าง
