ระเบียบวิธี

ชุดทดสอบเขียนแยกจากแม่แบบกลโกงที่ใช้สร้างระบบ ครอบคลุม 16 ประเภทกลโกง และข้อความปกติ 11 ประเภท รวมข้อความยาก (SMS OTP จริง, บิลค่าไฟจริง, ลูกขอให้โอนค่าเทอม, ข่าวเตือนภัย) ไม่มีการปรับกฎหลังเห็นผล การประเมินรันอัตโนมัติทุกครั้งที่ build (BenchmarkEvaluation) และตั้งเกณฑ์ขั้นต่ำกันประสิทธิภาพถดถอย (Recall ≥ 90%, FPR ≤ 10%, ทนการเลี่ยงคำ ≥ 85%) เวลาตรวจวัดบน JVM ของเครื่องพัฒนา

ข้อจำกัด: ข้อความทดสอบแต่งขึ้นโดยผู้พัฒนาตามรูปแบบกลโกงที่มีการเผยแพร่ต่อสาธารณะ ยังไม่ใช่ข้อความจากผู้เสียหายจริง และมีขนาด 120 ข้อความ ขั้นต่อไปควรเก็บข้อมูลจริงร่วมกับหน่วยงาน (เช่น ศูนย์ AOC 1441) และประเมินโดยผู้ประเมินอิสระ ผลของการฟังระหว่างคุย (แปลงเสียงเป็นข้อความ) ยังไม่ได้ประเมินกับสายจริง
